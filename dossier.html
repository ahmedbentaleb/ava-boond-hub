06Ce qui ne se négocie pas

Les six règles que l'audit cherche en premier dans le code rendu.

⛔ JamaisLe problème que ça évite
Un if métier écrit en durc'est LA faute que fait une IA qui code, parce que 99 % du code du monde la fait. Toute bifurcation a une clé au registre §C
Une colonne tenant_idADR-000 : une base = une société. L'isolation est la base, pas un WHERE qu'on oublie une fois
Un CHECK sur le code d'un référentielBoond a 14 états de candidat : ils entrent comme codes dans une catégorie, sans migration
Une icône de corbeille dans un écranM-8 : l'UI ne propose pas un geste que la base refuse
Additionner des montants hors des 4 vuesM-15 et la règle R-1 — le rôle d'agrégation n'a même pas les lignes
Un compte recopié d'un document à l'autreil diverge à la passe suivante. Le registre §E est la seule source
