User story 2 : Création d’une ressource depuis la fiche candidat
Description : En tant qu'utilisateur de l’application AVA-MANAGER,Je veux qu'un pop-up s'affiche lorsque je positionne le statut d'un candidat à "Collaborateur Avaliance",Pour que je puisse confirmer ou annuler la conversion du candidat à une ressource.
RG1 : Lorsque le statut d'un candidat est changé à "Collaborateur Avaliance", un pop-up s'affiche avec le message suivant : "Confirmez-vous la conversion du candidat en ressource ?".
RG2 : Le pop-up doit comporter deux boutons : "Confirmer" et "Annuler"
RG3 : Si l'utilisateur clique sur "Confirmer" :
Le statut du candidat devient "Collaborateur Avaliance".
Une nouvelle ressource est créée avec le statut "En cours".
Les informations ci-dessous du candidat sont automatiquement transférées à la nouvelle ressource.

User Story 3 : Création d'un candidat depuis LinkedIn
Description : En tant qu'utilisateur de l'application AVA-MANAGER, Je souhaite pouvoir cliquer sur une extension depuis le profil LinkedIn d'un candidat, Afin de récupérer automatiquement ses informations et les préremplir dans un formulaire affiché à l'écran.
RG1 : L'extension doit afficher un formulaire contenant les informations du candidat (Civilité, nom, prénom, Titre, Email, Téléphone, Ville, Pays, Etape, Disponibilité, Provenance, Précisez, Importer le DT, Importer le CV directement depuis LinkedIn. À détailler
RG2 : L'utilisateur doit voir un bouton "Créer un nouveau candidat" sur le formulaire.
RG3 : En cliquant sur "Créer un nouveau candidat", les informations doivent être transférées dans AVA-MANAGER, créant ainsi un profil candidat. (Voir le modèle ci-dessous):

User Story 4 : Création d'un contact depuis LinkedIn
Description : En tant qu'utilisateur de l'application AVA-MANAGER,Je souhaite pouvoir ajouter un profil LinkedIn en tant que contact dans le CRM,Afin d'intégrer ces informations directement dans la base de contacts d'AVA-MANAGER.
RG1 : L'utilisateur doit voir un onglet "CRM" sur le formulaire de l'extension.
RG2 : Les informations du contact doivent être pré-remplies automatiquement.
RG3: L'extension doit afficher un formulaire contenant les informations du candidat (Civilité, nom, prénom, Fonction, Email, Téléphone, Etat, Provenance.
RG4 : Un bouton "Créer un nouveau contact" doit permettre à l'utilisateur de transférer ces informations dans AVA-MANAGER en tant que nouveau contact. (Voir le modèle ci-dessous)

User Story 6 : Création d’une fiche projet à partir du besoin
Description : En tant qu’utilisateur de l’application, 
Je veux qu'un projet soit automatiquement créé avec les informations récupérées lorsque je sélectionne l’étape du besoin à "Gagnée",
RG1 : Lorsqu'un besoin passe à l’étape "Gagnée", un projet est automatiquement créé dans le système.

User Story 7 : Envoyer un CV depuis un candidat
Description : En tant qu'utilisateur, 

Lorsque je consulte le profil d'un candidat, je veux voir l'option "Envoyer le CV" pour pouvoir envoyer le CV du candidat à plusieurs contacts par e-mail.
RG1 : En cliquant sur le bouton « Envoyer le CV », je suis redirigé vers une interface de sélection des contacts ;

RG2 : La liste des contacts doit être filtrable par agences, pôles et Managers.
RG3 : Je peux sélectionner un ou plusierus contacts .

RG4 : Après avoir sélectionné les contacts quand je clique sur le bouton « Continuer », je veux être redirigé vers une interface de rédaction d'e-mail.

RG5 : L’interface de rédaction d’e-mail donne la possibilité à l’utilisateur de renseigner l'objet et le contenu de l'e-mail.
RG6 : Un bouton "Sélectionner un modèle" est disponible lors de la rédaction de l'e-mail. (Voir la US suivante).
RG7: Lorsque je sélectionne un modèle, le contenu de l'e-mail se remplit automatiquement.
User Story 8 : Création d’un modèle d’email
Description : En tant qu'utilisateur de l’application,
Je souhaite créer des modèles d'e-mail depuis la rubrique Emailing
RG1 : Dans la section e-mailing, une option "Créer un modèle" est disponible, en cliquant dessus, je peux saisir le nom du modèle, l'objet et le contenu.

RG2 : Un bouton "Créer" permet d'enregistrer le modèle avec un message de confirmation.

User Story 8 : Personnaliser l’email

En tant qu'utilisateur, je souhaite avoir des variables personnalisables dans mes modèles, pour personnaliser les e-mails envoyés.
RG1 : Des variables comme le nom de la société et le nom du contact sont disponibles dans les modèles.
RG2: Ces variables peuvent être insérées facilement dans le contenu lors de la création du modèle.
