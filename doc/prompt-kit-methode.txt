2.3 MATCHER — chaque élément relevé reçoit un verdict
  - ✅ déjà au modèle · ➕ ajouté aujourd'hui · ⛔ écarté AVEC son motif
  - puis on le range, et c'est la clé de tout le projet :
    | Genre | Ce que c'est | Où |
    |---|---|---|
    | MUR | un invariant que la base refuse (CHECK, trigger, EXCLUDE) | modèle métier + une assertion SQL par mur |
    | POLITIQUE | une bifurcation métier : clé, valeurs, défaut = ce que fait le client aujourd'hui | table `politique`, registre |
    | RÉFÉRENTIEL | une liste de valeurs : catégories FIXES (le code s'y fie), codes ADMINISTRABLES | tables `ref_*` |
    | MACHINE D'ÉTAT | les catégories et leurs transitions, chaque transition = une commande | machines d'état |
  - ⛔ « Tout paramétrable, rien en dur » : aucun if sur un libellé, aucun
    CHECK qui fige une liste de codes métier.
  - Ce qui ne se déduit pas d'un texte → une QUESTION AU CLIENT, rangée dans
    le hub (bouton Questions), réponse consignée (R1…Rn) puis reportée au
    canon. Tout ce qui se déduit, le BRAIN le tranche seul.

ANNEXE A — le récepteur de captures (outil qui a servi, tel quel)
─────────────────────────────────────────────────────────────────
"""Reçoit une capture par window.name : la page y range 'nom|dataURL', puis
l'onglet navigue ici (origine locale), et cette page POSTe le tout en same-origin."""
import base64, http.server, os, re
DEST = os.path.join(os.path.dirname(os.path.abspath(__file__)), "captures")
os.makedirs(DEST, exist_ok=True)

PAGE = b"""<!doctype html><meta charset=utf-8><title>recepteur</title>
<body style="background:#111;color:#ccc;font:14px sans-serif">recepteur<pre id=e></pre><script>
(async () => {
  const n = window.name || '';
  const i = n.indexOf('|');
  if (i < 0) { e.textContent = 'rien dans window.name'; return; }
  const nom = n.slice(0, i), png = n.slice(i + 1);
  const r = await fetch('/save?nom=' + encodeURIComponent(nom), {method: 'POST', body: png});
  e.textContent = await r.text();
  window.name = '';
})();
</script>"""

class H(http.server.BaseHTTPRequestHandler):
    def do_GET(self):
        self.send_response(200)
        self.send_header("content-type", "text/html; charset=utf-8")
        self.end_headers()
        self.wfile.write(PAGE)
    def do_POST(self):
        nom = re.sub(r"[^a-zA-Z0-9_-]", "", self.path.split("nom=")[-1])[:60] or "capture"
        corps = self.rfile.read(int(self.headers.get("content-length", 0))).decode()
        png = base64.b64decode(corps.split(",", 1)[1])
        with open(os.path.join(DEST, nom + ".png"), "wb") as f:
            f.write(png)
        self.send_response(200)
        self.end_headers()
        self.wfile.write(f"ECRIT {nom}.png {len(png)//1024} Ko".encode())
    def log_message(self, *a):
        pass

http.server.HTTPServer(("127.0.0.1", 8766), H).serve_forever()

Côté page (dans le navigateur, sur l'écran à capturer) :
  html2canvas chargé depuis cdnjs, puis
  const c = await html2canvas(document.body);
  window.name = 'nom-de-l-ecran|' + c.toDataURL('image/png');
  location.href = 'http://127.0.0.1:8766/';
  puis revenir à l'écran suivant.
