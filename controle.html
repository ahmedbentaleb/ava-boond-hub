Chaque niveau autorise le suivant. Celui qui code ne vérifie jamais son propre travail.

Les contrôles automatiques

ContrôleSa question
Le cliquetEst-ce que tous les tests sont verts ?
Le sabotageSi on casse le code exprès, est-ce que le test devient rouge ? Un test resté vert est aveugle.
La démoAvec une fausse Avaliance de taille réelle, est-ce que ça marche, et en moins de 150 ms ?
L'auditQu'est-ce que personne n'a vu ?
