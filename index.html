Ava Manager — Boond

Schéma métier · simulateur · audit des 59 écrans avec captures. Produit, pas un tenant.

Les cinq chemins

Bandes

Règle

Le bouton Créer d’une fiche est le vrai menu. Un besoin crée un positionnement. Un projet crée une prestation. L’inverse n’existe pas.

Deux lectures

Chef de projet

Le miniature n’est pas 13 listes. C’est C3 + C4. Sans positionnement, le staffing n’existe pas. Sans prestation, le projet est un titre.

Ordre : Société/Besoin → humain → Positionnement → Projet → Prestation → Action. Dashboard et reporting en dernier.

Hors v1 : Apps, facture client, paie, intranet, profils types, produits.

Auditeur senior

Candidat ≠ ressource (onglets différents). Positionnement = 1 besoin × (1 candidat XOR 1 ressource). Facture client : 403, hors cœur.

Compte = ressource + rôle + périmètre. Plan de charge = une vue, pas un objet.

59 captures. Les 16 listes du menu ne suffisent pas : le métier est dans les onglets, les +, les Kanban et les modales.
